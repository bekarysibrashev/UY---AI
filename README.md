# ÚY — AI Жилищный Навигатор Казахстана

> Сервис подбирает государственные жилищные программы Казахстана под конкретного пользователя — на основе его профиля и RAG-системы с реальными условиями программ.

---

## Что это

Большинство казахстанцев не знают какие жилищные программы им доступны и с чего начать. ÚY решает эту проблему: пользователь заполняет профиль (возраст, доход, город, семья) — AI анализирует его данные, находит подходящие программы из базы знаний и объясняет пошагово что делать.

Никаких звонков в банк и чтения PDF с gov.kz. Просто ответ на вопрос «что мне делать чтобы получить жильё».

---

## Возможности

- **Персональный подбор** - анализирует профиль пользователя и подбирает подходящие программы из базы
- **RAG по реальным условиям** - AI работает только с актуальными данными программ, не придумывает
- **Оценка вероятности одобрения** - для каждой программы выдаёт процент и объясняет почему
- **Пошаговый план** - конкретные шаги что делать, какие документы собрать
- **Уточняющий чат** - после анализа можно задать вопросы, история диалога сохраняется
- **Admin Dashboard** - аналитика по пользователям в реальном времени из Firestore

**Программы в базе знаний:** 7-20-25 · Нурлы Жер · Бақытты Отбасы · Жас Отбасы · Арендное жильё КЖК

## Как работает AI

```
Профиль пользователя
        ↓
RAG — база знаний жилищных программ РК
        ↓
Groq API → LLaMA 3.3 70B
        ↓
Структурированный ответ:
  • Подходящие программы + вероятность одобрения
  • Условия участия
  • Пошаговый план действий
  • Риски и важные моменты
  • AI-анализ профиля (сильные/слабые стороны)
        ↓
Firebase Firestore (сохранение сессии)
```

AI работает строго по базе знаний — не выдумывает программы и условия. Промпт содержит актуальные данные всех программ и требует цитировать источник при каждом утверждении.

## Быстрый старт

### 1. Клонировать и установить зависимости

```bash
git clone https://github.com/YOUR_USERNAME/uy-housing-navigator.git
cd uy-housing-navigator
npm install
```

### 2. Получить ключи

**Groq API** (бесплатно) - [console.groq.com](https://console.groq.com)

**Firebase** - [console.firebase.google.com](https://console.firebase.google.com) → создать проект → включить Firestore → скопировать конфиг

### 3. Вставить ключи в `public/app.js`

```javascript
const firebaseConfig = {
  apiKey: "...",
  projectId: "...",
  // остальные поля из Firebase Console
};

const AI_CONFIG = {
  apiKey: "gsk_...",  // Groq API key
  model: "llama-3.3-70b-versatile",
};
```

### 4. Запустить локально

```bash
npm run dev
# http://localhost:3000
```

### 5. Задеплоить

```bash
npm install -g firebase-tools
firebase login
firebase deploy
```
